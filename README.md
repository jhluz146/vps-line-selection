## 常见问题

**月流量用完后会怎样？**
官网只标注"Monthly Transfer"（月流量），没有明确超标后是限速、停机还是按量计费。如果你的业务流量不稳定，购买前问客服，或者选流量富余的套餐。

**能不能换IP？**
标准套餐通常只给1个IPv4，换IP需要额外付费或重新开机（可能分配新IP，也可能还是旧的）。如果你需要多IP或频繁换IP，住宅IP系列或独立服务器更合适。

**支持哪些支付方式？**
支持支付宝和USDT。

**能不能升级套餐？**
可以，但需要联系客服操作。降级通常不支持，或者要重新开机迁移数据。

**数据备份怎么办？**
部分套餐标注RAID10数据保护，但RAID只防硬件故障，不防误删、被黑、机房火灾。重要数据必须自己做异地备份，不要指望商家帮你保管。
